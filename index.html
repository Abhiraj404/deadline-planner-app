    Moodle (optional)

    To save a Moodle sign-in session, run .\.venv\Scripts\python.exe auth.py moodle in PowerShell, sign in, then press Enter. Keep the calendar URL private: it can grant access to your calendar.

    Outlook (optional)

    Then run .\.venv\Scripts\python.exe auth.py outlook.

    Gmail (optional)

    Save your Google OAuth desktop client file as credentials.json in the data folder, then run .\.venv\Scripts\python.exe auth.py gmail.
